# 工具详情搜索

工具详情搜索复用统一的搜索面板，但把工具正文扫描和命中校验放在独立的 `src/ui/tool_search.rs`。`TimelinePanel` 只负责从详情视图转交入口，`src/ui.rs` 负责切换 UI 模态；执行事实仍由 Core 和 `tool_details` 所有。

## 使用方式

- 在时间线工具详情中按 `s` 或 `Ctrl+F` 进入工具搜索。
- 在搜索面板按 `F5` 循环切换消息、工具和两者，`F8` 切换工具类别，`F9` 切换生命周期。
- `n/N` 或方向键在统一命中列表中移动，`Enter` 打开选中的工具详情，`Esc` 返回或关闭。
- 搜索支持 command、cwd、parameters、result、output 字段，按 UTF-8 字节范围定位，大小写敏感且不使用正则表达式。

## 过期命中与内存边界

工具命中只保存完整 `ToolDetailLocator`、字段枚举、UTF-8 范围和内容 `revision`，不保存工具正文或完整 Core 快照。字段或生命周期实际变化时 `revision` 递增；显示、导航和 Enter 打开前都会重新从当前快照校验 locator、revision、字段存在性和字符边界。条目淘汰、轮次退休或输出变化后，旧命中只能显示过期提示，不能打开旧正文。

消息搜索只保留匹配消息投影；工具模式不保留消息来源。消息与工具同时搜索时共用有界的 512 个命中槽位，并保留准确总数。查询、结果和工具正文不会进入 Core 命令、journal、JSONL 或历史导出。

## 验证

单元测试覆盖字段过滤、线程/轮次过滤、中文与 emoji 的 UTF-8 范围、revision 变化和淘汰。Windows ConPTY 夹具覆盖从时间线详情进入搜索、聚合输出命中、Enter 打开详情、返回路径及零额外 RPC。
