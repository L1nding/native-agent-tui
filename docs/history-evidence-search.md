# 历史证据搜索

F12 历史面板显示会话列表后即可使用 `/` 或 `Ctrl+F` 搜索脱敏证据元数据；已打开会话时，搜索范围缩小到当前 session。

## 使用方式

- 输入查询文本并按 Enter 提交；查询字段限制为 1024 个 UTF-8 字节。
- 按 F6 在 `all`、`lifecycle`、`output`、`tool`、`request`、`waiting` 类别间切换。
- 使用 Up/Down 或 `j`/`k` 选择命中，按 Enter 跳转到对应 session 的事件序号。
- 后台搜索可取消；打开其他会话、返回会话列表或按 F12 返回实时界面时，旧搜索会被取消。

## 搜索范围与隐私

搜索只读取固定的已提交 journal 前缀；从会话列表启动时，每个当前保留 session 都分别固定自己的前缀，从详情启动时只固定当前 session。未提交尾部不会进入结果，结果会显示参与 session 数、提交水位和未提交尾部提示。重复快照中的旧证据会去重，命中数量和元数据总量有界，超出部分显示为省略数量。

查询可以匹配内部元数据以便定位活动、线程、turn、工具或请求证据，但界面只显示脱敏摘要。提示、答案、秘密、原始命令、路径、provider 状态和原始工具输出不会写入搜索结果，也不会通过历史搜索导出。

历史搜索是只读操作。命中事件只能定位历史观察结果，不能恢复任务、发送请求或改变当前执行。
