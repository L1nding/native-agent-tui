# 观察提示与执行事实分离

2026-10-03，已接受。Python 脚本曾仅凭进程存活和子代理未结束判断任务正常，无法说明最近进展和等待条件。决定由 Core 统一提供活动证据和注意级别，TUI 与 JSONL 消费者共享同一份投影；静默、计时器和关闭提醒均不能改变任务终态或触发模型请求。

恢复先重建脱敏后的观察状态，继续执行必须经用户确认并创建新 attempt。此选择放弃自动续跑的便利，避免重复文件或 shell 副作用。具体边界见[可观测性契约](../native-agent-tui-observability.md)；发布顺序见[产品计划](../native-agent-tui-plan.md)。
